## 3. 코드 품질 및 성능 (Quality & Performance)

### 3.1 긍정적 요인
- **사용자 경험:** 서버 응답을 기다리지 않고 UI가 즉시 갱신되어 매우 부드러운 사용성 제공.
- **데이터 보안:** 클라이언트에서 API 키를 노출하지 않고 서버 액션을 통해 구글 API와 통신하는 안전한 구조.
- **확장성:** 담당자별 리소스 계산 로직이 배열 메서드(`reduce`, `map`)를 활용하여 태스크 양이 늘어나도 유연하게 대응 가능.

### 3.2 개선 필요 사항 (Minor)
- **필터 UI 고도화:** 현재 상태 필터는 탭 방식이나, 담당자 필터는 검색어에 통합되어 있음. 향후 담당자 전용 Select UI 추가 고려 가능.
