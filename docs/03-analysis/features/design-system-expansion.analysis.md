## 3. 코드 품질 및 성능 (Quality & Performance)

### 3.1 긍정적 요인
- **유지보수성:** 비즈니스 로직이 `lib/system-utils.ts` 한 곳으로 모여 향후 변경 시 일괄 적용 가능.
- **가독성:** `GanttChart.tsx`의 코드 길이가 줄어들고, 선언적인 컴포넌트(`StatusBadge`, `UserAvatar`) 사용으로 가독성 대폭 향상.
- **재사용성:** 신규 구축된 3종의 UI 컴포넌트는 프로젝트 내 모든 페이지에서 즉시 사용 가능함.

### 3.2 개선 필요 사항
- **Modal 컴포넌트 독립화:** 향후 프로젝트 규모 확장 시 `Radix UI` 기반의 완전 독립형 `Modal` 컴포넌트 추출을 최종 단계로 권장함.
