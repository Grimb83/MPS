## 2. 문제 정의 및 솔루션 (Problem & Solution)

### 2.1 현재 문제점 (As-Is)
- **읽기 전용:** 데이터 수정 시 반드시 구글 시트 앱을 직접 열어야 함.
- **분석 부재:** 전체적인 프로젝트 지연 현황이나 담당자별 리소스를 한눈에 파악하기 어려움.
- **검색 한계:** 대규모 프로젝트 진행 시 특정 태스크를 찾기 위해 스크롤에 의존.

### 2.2 해결 방안 (To-Be)
- **양방향 동기화:** 웹 대시보드에서 태스크 상태 변경 및 신규 등록 시 구글 시트에 즉시 반영.
- **지능형 위젯:** 지연(Delayed) 태스크 자동 감지 및 담당자별 리소스(Man-month) 시각화 위젯 도입.
- **고급 필터링:** 실시간 검색바 및 속성별 다중 필터링 시스템 구축.

---

## 3. 핵심 기능 요구사항 (Requirements)

### 3.1 [Core] 데이터 연동 (Data Integration)
- [ ] **Write API:** 구글 시트 특정 행(Row) 수정 및 신규 행 추가 로직 구현.
- [ ] **Sync Indicator:** 데이터 저장 중/성능 알림 시각화.
- [ ] **Optimistic Update:** 저장 전 UI에 먼저 반영하여 사용자 경험 향상.

### 3.2 [UI/UX] 스마트 대시보드 (Smart Dashboard)
- [ ] **Stats Card:** 지연 태스크 수, 진행률, 총 태스크 수 요약 카드 고도화.
- [ ] **Resource Chart:** 담당자별 업무 할당량 시각화 (Simple Bar Chart).
- [ ] **Alert System:** 마감일이 지난 태스크에 대한 시각적 강조 효과.

### 3.3 [Features] 데이터 핸들링 (Data Handling)
- [ ] **Global Search:** 태스크명 및 비고 내용 대상 실시간 검색.
- [ ] **Multi-Filter:** 담당자, 상태(진행/대기/완료/취소), 우선순위별 필터링.

## 5. 단계별 일정 (Phases)

1.  **Phase 1 (Design):** 양방향 데이터 흐름 및 신규 위젯 UI 설계.
2.  **Phase 2 (Do - Write):** 구글 시트 쓰기 API 연동 및 서버 액션 구현.
3.  **Phase 3 (Do - UI):** 대시보드 위젯 및 고급 필터 시스템 구현.
4.  **Phase 4 (Check/Act):** 실시간 연동 테스트 및 성능 최적화.
