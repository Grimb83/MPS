# ?? Plan: Row Hover Enhancement

## 1. 개요 (Overview)
- **기능명:** 과업 테이블 행 호버 강조 강화
- **목적:** 모든 행의 배경색이 동일하여 발생하는 시각적 혼동을 방지하고, 현재 마우스가 위치한 과업을 명확히 식별할 수 있도록 함.
- **범위:** `components/task-table.tsx` 및 관련 스타일링.

## 2. 요구사항 (Requirements)
- [ ] 마우스 호버 시 행의 배경색을 더 명확한 색상으로 변경 (현재 5% -> 10~15% 수준).
- [ ] 호버 시 좌측에 포인트 보더(Border) 또는 그림자(Shadow) 효과 추가 검토.
- [ ] 트랜지션(Transition) 효과를 적용하여 부드러운 인터랙션 제공.

## 3. 예상 결과 (Expected Value)
- 사용자가 현재 어떤 과업을 보고 있는지 시각적으로 즉각 인지 가능.
- 테이블 가독성 및 UI/UX 품질 향상.
